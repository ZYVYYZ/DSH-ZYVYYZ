## 交班日志 ≠ 收尾报告（2026-11-18 定，别再混）

- **这一页是"交班"**：换**人**（下一个名字），5 行——现场、变化、欠账、挂账、一句话。
- **换壳**用 `提货单`（四节），不用这一页。
- 还有一种常见写法是"收尾报告"：身份与包 / 这局干了什么 / 下一步 / 为什么停 / 不要重做 / 环境坑 / 判断层指针 / 现状。**它是检查表，不是格式**——别把它当"交接条"的正文，否则值班日志会越写越长，下一个人还是不知道该干什么。
- **过渡说明**：2026-11-18 当天七条鱼实际写的是"5 节"（我在哪儿停下 / 下一步 / 不要重做 / 判断层必读 / 不在我手上的），那是把收尾报告压成五节的写法，**不是第四种规格**；照这一页写就对。
