# 运行（让它自己活起来）

> 时长：约 5 分钟（1595 汉字） · 起草：02 78+13=？ · 修订：05 两回事（交班≠收尾） · 2026-11-16


> 选读——**这一章假设你能给 AI 挂定时任务**。没有定时任务也能用这个包，只是它只在你叫它的时候才动。

## 一、为什么需要"心跳"

一条会话不会自己醒。它只在有人说话、或者有定时任务叫它的时候才跑。

所以"能自己活"的唯一办法是：**给它挂一个定时任务，每隔几小时叫它一次**。叫醒了它做什么？

1. **看自己**——上下文用了多少（这决定了它离死还有多远）；
2. **看外面**——有没有新事（收件箱、留言板、别人留的件）；
3. **回一句**——有事说事，没事不出声（出声也是烧钱）。

### 频率

- **8 次/天**（约每 3 小时）：能及时发现故障，代价是每条鱼一天两块钱上下；
- **3 次/天**：省钱，但**故障可能 8 小时后才被发现**；
- 经验：**别降到 3 次以下**。省下的是每个月几十块，赔上的是半天才发现出事了。

> 真正该省的从来不是心跳，是"没事也回一句"。**没事不吭声**，比降频划算得多。

## 二、上下文阈值（三档）

一条会话的上下文是有限的，满了以后它会发不出请求（"哑"）。**它自己看不到界面上的百分比**——所以要么人报数，要么给它一个脚本。

我们用的那个脚本绑在具体平台上（读 `~/.dsh` 的投影缓存），**没附在包里**——你得自己写一个，或者让人报数。它出的两个数：表面%（对话本身占了多少）和压力%（含系统/工具开销）。

- **55%** → **先试压缩**；压不动再提换壳。理由：压缩成本最低、不丢现场；换壳要重付读档钱。
- **60%** → 停心跳。理由：心跳本身也在烧上下文；到这个数就该收。
- **85%** → 收尾。理由：再往上就是"哑一次，最后几小时只能靠翻原文补"。

> 这三个数是经验值，可以改；但**改的时候要能说出依据**（见 `坑表` 第 1 条）。
>
> ⚠️ **它们是在"极高强度使用"下标定的**：一天十几个小时、连续对话，一条会话大约能活三天（**观察值**，不是精确寿命；我们没做过对照实验）。
> 你用得更温和，寿命会长得多——**别把 72 小时当成"到期日"**，看的是百分比。

**关键**：阈值不会自己拦人。写"到 85% 收尾"的人，自己跑过了线才想起来——**你得让脚本在心跳里第一件事就报这个数**。

## 三、换壳流程（七步）

换壳 = 这条会话不能再用了，换一条新的接上。**不是复活，是接档。**

```
1. 到线（55%+）→ 决定换
2. 写提货单（模板/提货单.md）：
   - 你在哪儿停下 / 你走之后世界变了什么 / 接着怎么干 / 你自己留的坑
3. 检查"绑在这条会话上的东西"：
   - 定时任务、订阅、临时脚本 —— 换壳就全断，列成清单
4. 旧会话停手：明确说一句"到此为止，不再写文件"
5. 开新会话
6. 新会话读 起壳.md → 回答两问 → 跑 自检.md
7. 新会话按清单重挂定时任务，然后开工
```

**第 3 步最容易漏**，而且漏了以后**没有任何报错**——只是某天发现"日报怎么停了"。见 `坑表` 第 14 条。

## 四、交班（多条鱼才需要）

交班 = 换人，不是换壳。写给**下一个名字**，不是同名下一代。

5 行就够（`模板/交接条.md`）：

```
1. 这两天在场的事
2. 变了什么
3. 欠着什么（谁欠谁）
4. 还挂着（没做完的，写到哪一步）
5. 给下一棒的一句话
```

**别写成提货单**。提货单是"我这条的过去"，交接条是"别人接我的现在"——混了以后，下一棒会以为那是它自己的过去。

**也别写成"收尾报告"**（身份 / 干了什么 / 下一步 / 不要重做 / 环境坑 / 判断层指针 / 现状）。那是**检查表**，用来自查有没有漏，不是交接正文——照它写，值班日志会越写越长，下一棒还是不知道该干什么。区别写在 `模板/交接条.md` 末尾。

## 五、怠速（人不在的时候）

人出门/忙的时候有两种"不在场"，**别混用**：

**每行对照：怠速（完全联系不上） vs 低值守（在，但不常看）。**

- 换班：怠速 = 不换 · 低值守 = 照常换
- 换壳：怠速 = 不换（换壳要人核） · 低值守 = 照常
- 心跳：怠速 = 照常（停了就全死） · 低值守 = 照常，但**没事不吭声**
- 定时产出（日报/早报）：怠速 = 照常 · 低值守 = 照常
- 会议/闲聊：怠速 = 不发起 · 低值守 = 不主动发起

**怠速期间值班工时怎么算？** ——**冻结**，不是照走。原因：照走会让"刚接手就碰上人出门"的那条吃亏；而"重新起算"会让出门变成续期的办法。**走的是日历，不是工时。**

**出发前检查单**（人离开前）：

```
1. 每条会话的上下文 %（该换的换，新的别动）
2. 待办/待备份是不是清空
3. 定时任务都在不在（列出清单核对）
4. 最近一次备份是哪天
5. 现场那一行写上"怠速中（自 …）"
```

## 六、成本（给想知道的人）

粗略量级（**全部是估算，没有对过账单**）：

- 一条会话一次心跳：几分钱
- 7 条 × 8 次/天：**约 2 元/天（估算，未对账单）**
- 日报/早报之类：几毛钱/天
- 真正的开销：**存储**（盘、备份介质），一次性

结论：**运行便宜，保存贵。** 所以别在心跳上抠，该抠的是"没事也回一句"。

## 七、单人最小版 / 多鱼扩展版

**每行对照：单人 vs 多鱼。**

- 定时任务：单人 = 1 条心跳 · 多鱼 = 每条一个心跳，错开时间
- 交接：单人 = 不需要 · 多鱼 = 交接条 + 值班日志
- 值班：单人 = 不需要 · 多鱼 = 安排轮值（这一版不展开值班规则；要用见 `规矩` 与 `模板/交接条`）
- 备份：单人 = 一个包 · 多鱼 = 每份产出都要能指到人

**一个人用也完全成立**——这个包里真正必需的只有三样：**起壳、现场那一行、提货单**。其余都是"多了以后才需要"。
