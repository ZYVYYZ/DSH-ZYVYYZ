# 版本记录

## v0.4.1 · 2026-11-19

**修包。书的内容没改一个字。**

- **权限**：v0.4 的包里，解压后 `README.md` / `安装.mjs` / `校验.mjs` 是 0 权限（Mac/Linux 上打不开）。打包脚本 `打包.mjs` / `打包传火.mjs` 补了统一 `chmod 644`；
- **传火包 `README.md` 重写**：补「包里有什么（6 个文件）」「三张纸是哪三个」「第一行怎么写（带例子）」「路径怎么给」「AI 读不到你电脑上的文件怎么办」「**怎么算搭好了**」；
- **传火包 `00-给鱼的.md` 重写**：去掉「主人派来的下属」这个角色假设（现实是用户直接把文件夹丢给 AI），补 7 个文件清单、`校验.mjs` 用法与 Node 依赖、并在哈希那段说清「包内清单只能证明文件没坏，不能证明来源」；
- 两处时间口径统一为「十分钟」。

**为什么发**：v0.4 发出后做了两轮黑盒验收——干净会话，一个只读 `README.md`，一个只读 `00-给鱼的.md`。**两个都走不完**，而且各自独立地指出同一件事：**没有任何一步说了「做到什么样算成了」。**
