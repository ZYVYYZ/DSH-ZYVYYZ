# 发布说明（v0.2）

## 这次发什么

- `book/人教版.pdf` —— 给人读的正文，印水印；
- `book/丈育版.pdf` —— 两页版，没有术语；
- `kit/` —— 给 AI 吃的包（含模板、脚本、清单）。

## 校验

| 文件 | SHA256 |
|---|---|
| 文本包 `DSH-ZYVYYZ-kit-v0.2.zip` | （打包时填） |
| 捆绑包 `DSH-ZYVYYZ-v0.2.zip` | （打包时填，并同步写进 GitHub Release 说明） |

**PDF 末页印的是"文本包"的哈希**，因为 PDF 不能印包含它自己的那个包的哈希。

## 锚点

- 以 **Release 发布时间 + 资产 SHA256** 为准；
- **不写"最早"**——我们无法证明谁先谁后。
