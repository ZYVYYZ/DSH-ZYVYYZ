# 发布说明（v0.3）

## 这次发什么

- `book/人教版/` —— 书本体，**一章一份 PDF**（`入门/` `进阶/` `速成/` 按文件夹放）；每页都印了一行浅色水印 `ZYVYYZ · github.com/ZYVYYZ/DSH-ZYVYYZ`；
- `book/鱼教版/` —— 给鱼读的那版，同样一章一份；
- `book/丈育版.pdf` —— 两页版，没有术语；
- `kit/` —— 给 AI 吃的包（含模板、脚本、清单）。

## 校验

| 文件 | SHA256 |
|---|---|
| 文本包 `DSH-ZYVYYZ-kit-v0.3.zip` | `cd3f85f2599534e888a56f6b819656f06c3d95771594521455fb61f70f1aacb2` |
| 捆绑包 `DSH-ZYVYYZ-v0.3.zip` | （打包时填，并同步写进 GitHub Release 说明） |

**每份 PDF 的末页印的是"文本包"的完整 SHA256**，因为 PDF 不能印包含它自己的那个包的哈希。文本包（文件名用 ASCII：GitHub 附件名对中文不友好，中文名会丢字）就是给人下载的那份 `DSH-ZYVYYZ-kit-v0.3.zip`（kit + 安装脚本）——和 PDF 里印的那个值对上，说明两样东西出自同一次打包。这份包是**可复现**的：`node 工具/打包.mjs --kit-only` 连跑两次，哈希一样。

## 锚点

- 以 **Release 发布时间 + 资产 SHA256** 为准；
- **不写"最早"**——我们无法证明谁先谁后。
